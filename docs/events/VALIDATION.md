# Проверка поставки

Дата: 18 сентября 2026. Python 3.12 в среде выполнения.

- 14 автоматических тестов: все прошли.
- HTTP: проверены `/health`, POST `/assess`, сохранённый `/runs/{id}`, исходный `/snapshots/{id}`.
- Реальный исторический запрос 2024-05-10 12:00 UTC, длительность 6 часов, поиск начал 6 часов: получена 201 нормализованная запись из DONKI, рассчитано 7 окон.
- Реальный текущий запрос: проверены ответы DONKI, NOAA Kp/GOES/alerts, JPL CAD.
- SOCRATES: получен полный CSV размером 17 416 442 символа, выделены 3 записи с NORAD 25544. Это число записей в отчёте, не число ударов и не обязательно число сближений внутри выбранного шестичасового окна.
- Исправлена совместимость HTTP Accept для CSV; повторное получение успешно.
- Исторические сближения: нет архива в комплекте, явно `archive_unavailable`.
- Микрометеороиды: модель не подключена, явно `model_required`.
- Оба реальных примера возвращают `insufficient_evidence` для окончательного выбора окна.

Файлы examples с реальными данными обновлены из сохранённого кеша после проверки; это не синтетические примеры. Их `generated_at` — время пересчёта, `fetched_at` у источников — время скачивания. Синтетический только `demo_result.json`.

Это интеграционная проверка программы, не подтверждение прогностической точности или пригодности для оперативного управления ВКД.
