# Охват Phenomena и смысл для ВКД

Это реестр проектных решений по разделу [NOAA Phenomena](https://www.spaceweather.gov/phenomena), проверенному 18.09.2026. Раздел содержит описания, а не единый API. Поэтому сервис обращается к конкретным продуктам. «Все категории рассмотрены» не означает, что для каждой существует пригодный прогноз воздействия на МКС.

| Категория сайта | Решение в этой версии |
|---|---|
| Aurora | Отдельный фактор не добавлен: может повторять геомагнитный сигнал. Для траектории нужна карта авроральной зоны. |
| Coronal Holes | HSS из DONKI как связанное событие; распознавания дыр по изображениям нет. |
| Coronal Mass Ejections | DONKI CME — контекст; WSA-ENLIL — интервалы ожидаемого воздействия возле Земли. |
| Earth's Magnetosphere | DONKI MPC — контекст; локальная граница магнитосферы не рассчитывается. |
| F10.7 cm Radio Emissions | Не подключено; потенциальный вход модели атмосферы, не самостоятельное острое событие. |
| Galactic Cosmic Rays | Не подключено; нужна модель фоновой радиационной среды. |
| Geomagnetic Storms | DONKI GST, прогнозные/наблюдаемые интервалы NOAA Kp. |
| Ionosphere | Отдельная локальная модель не подключена. |
| Ionospheric Scintillation | Нет метрики отказа связи без трассы, частоты и соответствующего продукта. |
| Radiation Belts | DONKI RBE — контекст; перенос измерения на орбиту МКС не реализован. |
| Solar EUV Irradiance | Не подключено; возможный вход модели термосферы/ионосферы. |
| Solar Flares (Radio Blackouts) | DONKI FLR и собственные эпизоды по рентгеновскому потоку GOES. |
| Solar Radiation Storm | DONKI SEP и собственные эпизоды по протонному потоку GOES. |
| Solar Wind | DONKI HSS и IPS; непрерывные L1-измерения и модель переноса не подключены. |
| Sunspots/Solar Cycle | Не подключено; возможный предиктор, не непосредственное воздействие на окно. |
| Total Electron Content | Не подключено; нужна привязка TEC к радиотрассе и времени. |
| Bright spot in CME image | Справочная статья, не самостоятельный механизм угрозы. |

Дополнительные механизмы:

| Класс объектов | Реализация | Что нельзя утверждать |
|---|---|---|
| Каталогизированные фрагменты | SOCRATES CSV, фильтр NORAD 25544, тип `fragment` по имени DEB | Это ещё не предсказание удара |
| Ступени ракет | Тот же источник, тип `rocket_body` по имени R/B | Классификация по имени эвристическая |
| Спутники и неустановленный тип | `payload_or_unknown` | Не каждый объект рядом — мусор |
| Мелкий неотслеживаемый мусор | `model_required` | Нельзя получить из списка крупных объектов |
| Спорадические микрометеороиды | `model_required` | Нельзя вывести из числа астероидов |
| Метеорные потоки | Требуется подключение прогноза потока/модели и геометрии | Наземный ZHR нельзя прямо принять за поток на скафандр |
| Астероиды/кометы возле Земли | JPL CAD, только `context` | Геоцентрическое сближение не является сближением с МКС |

[NASA MEO](https://www.nasa.gov/meteoroid-environment-office/) занимается метеороидной средой, моделями и прогнозами метеорных потоков. В этой версии нет выдачи выдуманных отдельных траекторий микрометеороидов.

Для будущего модуля потоков разумный контракт: `flux`, единицы площади/времени, порог размера/массы, направление, временной профиль, версия модели, условия на орбите. При обоснованной пуассоновской модели можно вычислять λ = ∫F(t)·A_eff(t)dt и P(≥1) = 1−exp(−λ). Это вероятность попадания частицы выбранного класса, а не автоматически вероятность пробития, травмы или гибели. Сейчас этот расчёт не реализован: нужных входов нет.
