# COSMOHACKATON — расчёт внешних факторов ВКД

## Что реализовано

Пакет `data` разделяет получение данных (`adapter.py`) и расчёты факторов в
`data/conditions`. `Window` нормализует границы в UTC и проверяет требование
ТЗ 1–8 часов. `DebrisCalculator` анализирует сближения с техногенным мусором
и поток микрометеороидов. `WindowComparator` сравнивает два и более окна
одинаковой длительности; при недостатке данных или статистически равных
оценках он возвращает «требуется дополнительная проверка», а не объявляет
окно безопасным.

## Запуск

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
```

`requests` используется адаптером при наличии, но для импорта и простого
офлайн-тестирования предусмотрен fallback на `urllib`. `skyfield` нужен только
для расчётов, использующих TLE. Исторический режим не подставляет современный
TLE: если архив недоступен, результат помечается отсутствующим.

## Соответствие ТЗ

| Требование | Реализация |
|---|---|
| 1–8 ч и UTC | `data.window.Window` |
| Траектория/освещённость/связь/тепло/протоны | существующие калькуляторы `conditions` |
| Мусор и метеороиды | `conditions.debris.DebrisCalculator` |
| Сравнение одинаковых окон | `window_comparator.WindowComparator` |
| Неполные данные | `missing_data`, `data_coverage_pct`, отложенная рекомендация |
| Историческая честность | адаптер не использует фальшивый исторический TLE |

Числовой `risk_score` для мусора — приоритизационная эвристика, не вероятность
столкновения; в интерфейсе необходимо показывать исходные расстояния, время,
источник и время публикации наблюдения.
