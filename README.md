# cosmohackaton

## Inception

### ключевая задача

- Сервис самостоятельно *получает открытые данные, выделяет значимые факторы, оценивает их развитие и сравнивает возможные окна проведения работ*
- Каждый *вывод* должен быть связан с исходными наблюдениями или прогнозами

### предметная область

- положение станции
- состояние космической среды
- ожидаемые события

#### особенности

- разная частота обновления
- неодинаковая точность
- частично произошедшее, частично прогноз, частично статистика

### входные и выходные данные

#### входные

- планируемое время
- длительность сеанса

#### выходные

- внешние факторы
    - оценка их значимости
    - время проявления
- варианты окон
- недостающие данные

### исследовательская часть

#### космическая погода

#### космический мусор
